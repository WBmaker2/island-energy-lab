# Island Energy Lab — 이미지 교체 적용 기준

2026-09-15. 이 문서는 이번 이미지 교체에 적용하는 검토된 기준이다.

- 기존 중·고등 한국어 학습 앱의 sky/slate 계열, 시스템 글꼴, 라이트 모드, 컴포넌트 배치를 유지한다.
- `island-energy-lab/MASTER.md`는 UI UX Pro Max가 출력한 검색 원자료다. 아동용 글꼴, 인디고 팔레트, 마케팅 페이지 구조는 이번 앱에 맞지 않아 채택하지 않는다.
- 생성 그림은 절제된 입체 일러스트, 바다의 청록·푸른색과 녹색 지형을 사용한다. 낮밤 이미지가 달라도 앱 표면은 밝게 유지한다.
- 그림은 수치 없는 가상 섬 맥락만 전달한다. 한국어 시설 설명·현재 시각·충전/방전/정전 판정은 코드로 표시한다.
- 그림에는 문자, 로고, 축, 수식, 측정값을 넣지 않는다. 차트·수지표를 생성 이미지로 바꾸지 않는다.
- 이미지 비율에 맞는 공간을 예약하고 작은 화면에서도 전체 장면을 볼 수 있게 한다. 새 애니메이션이나 의존성을 추가하지 않는다.
